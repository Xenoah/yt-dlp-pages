はじめての実行
Python 3.10以降、yt-dlp、FFmpegを導入してから、ターミナルに貼り付けて実行してください。
python -m pip install -U "yt-dlp[default]"
生成コマンドは選択中のシェル専用です。cmd.exeには直接貼り付けないでください。

知っておくと便利なこと
GitHub Pagesだけでダウンロードできますか？
GitHub Pagesは静的サイトなので、Python製のyt-dlpを実行できません。この画面を操作するPC上でブリッジを起動してください。PCに何も導入せずにブラウザだけで実行する方式ではありません。
FFmpegとJavaScriptランタイムの導入
動画と音声の結合、音声変換、メタデータの埋め込みにはFFmpegが必要です。YouTube向けにはDenoまたはNode.jsも導入してください。
Windows PowerShell：
winget install --id Gyan.FFmpeg -e
winget install --id DenoLand.Deno -e
macOS（Homebrew）：
brew install python ffmpeg deno
インストール後はブリッジのウィンドウを閉じて、起動し直してください。サイト側の変更により、yt-dlpの更新が必要になる場合があります。
接続できない場合
ブリッジが動いているか、接続キーが一致するか確認してください。Chrome / Edgeでアクセスを拒否した場合は、サイト設定からローカルネットワークへのアクセスを許可します。ブラウザの制限で接続できない場合は、起動セットのフォルダーで python bridge.py --local を実行して同じ画面をローカルで開けます。
保存先・スマートフォン・履歴について
標準の保存先はPCの「ダウンロード / yt-dlp-pages」です。python bridge.py --output "D:/Videos" で変更できます。ブリッジは操作中のPC専用で、スマートフォンから別のPCへの接続には対応していません。ジョブ履歴はブリッジを終了すると消えますが、保存ファイルは残ります。
ログインが必要な動画は？
この画面からCookieやアカウント情報は送信できません。ログイン、DRM、地域制限などによって取得できない動画があります。必要な場合はコマンド生成を利用し、ご自身の環境でyt-dlpを操作してください。
